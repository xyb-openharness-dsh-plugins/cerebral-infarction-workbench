# 阶段计划（M1）

- **P0/M2 原型**：S1、S2、首页设置入口、合成资料；实际点击预览并记录hash。用户确认前仅为草案。
- **P1/M3 模型冻结**：只在原型确认后复核主体、来源、时间精度、授权和快照关系；过兼容与修订走查。
- **P2/M4 数据**：核验中国官方指南原文、临床试验登记数据集的许可/字段/更新时间；只用公开数据和合成数据，禁真实病例。未取得可信数据则如实空缺，不伪造匹配结果。
- **P3/M5 服务层**：SQLite/版本化API/本地目录，DHS服务caller上下文、`newSession`/`subscribe`和原生面板契约经宿主文档核对。
- **P4/M6 包与测试profile**：实际npm包内容与测试profile脚本可验证部分；DSH Desktop安装/退出重开/点击走查未验证。
- **P5/M7–M8**：只准备包/市场/变更稿，不发版、不打tag、不投稿。
- **P6/M9**：按TEST-CASES真实跑最多2条核心用例；执行check/test及五项门禁；版本统一0.2.0；报告引用证据。

本计划不等于各关口已批准。
