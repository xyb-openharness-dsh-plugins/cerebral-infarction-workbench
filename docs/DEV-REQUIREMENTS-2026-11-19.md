# 开发硬约束（2026-11-19）

- 以用户签认的M2原型SHA-256 `26b237db5774b795d105832aef5ae8750899349bf1b176c60f8ddd7e75ded026` 和模块范围为UI合同；不改写该原型文件。
- 急症优先；所有记录为可选，呼救不依赖档案/网络/Agent；不诊断、不提供用药/个体治疗建议。
- 只使用公开来源与合成数据；不得将真实患者资料入仓；来源需注明访问日期和原件核验状态。
- schema冻结后仅追加迁移；来源与修订可追踪；未知值保持unknown/null。
- 数据默认留在用户主动选择的本机目录；取消目录选择无副作用；限制目录边界、文件类型与大小，不自动上传/解析文件内容。

- 每个里程碑逐条追加证据并更新PROGRESS后提交、推送；不得覆盖历史证据；所有失败如实记录。
