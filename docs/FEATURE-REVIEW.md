# 功能取舍复核（M1）

| 候选 | 决定 | 依据/待核 |
|---|---|---|
| FAST/中风120 | 一期；在呼救入口旁呈现 | NHC 2024官方指南；本地临床审查待完成 |
| 溶栓/取栓窗口倒计时 | 不做 | 个体资格取决于检查/影像/临床团队；避免误导与延误 |
| 呼救电话/手动号码 | 一期 | 地区化号码待部署确认；不得全球固定为120 |
| 具体医院/最短路线 | 暂缓 | 当地卒中中心实时/转运规则数据未取得 |
| 院前交接卡 | 一期 | 降低临场回忆负担的设计假设；用户研究待验证 |
| 资料整理与复诊问题 | 一期次级 | 价值合理但脑梗死患者具体任务证据较弱；原型评审再决定 |
| 用药、血压或营养处方 | 不做 | 可能造成患者自行改变治疗；范围不含治疗建议 |
| 试验匹配 | M4候选 | 只呈现登记研究原文及来源，纳入/资格由研究团队确认；当地数据和注册研究检索需另做核验 |
