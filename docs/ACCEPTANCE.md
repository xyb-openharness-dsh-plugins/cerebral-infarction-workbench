# 验收标准（M1 初稿）

真实业务验收必须在原型签认后细化；当前只定义可观察的场景预期，不宣称已测试。

| ID | 预期 | 证据类型/状态 |
|---|---|---|
| ACC-EMR-01 | 任意急症页面无需登录/输入即可显示立即联系当地急救服务的入口；流程不被表单、AI或动画阻断 | 原型待做；生产待实现 |
| ACC-EMR-02 | 急症信息包含 FAST 与其他突发警示；提示明确即使症状消失也求助；不输出“没事/排除卒中” | 原型待做；医学审核待完成 |
| ACC-EMR-03 | 所有交接字段可跳过/标未知；输出来源标记为用户/照护者提供；不建议等待、自驾、偏方、加减药 | 原型待做 |
| ACC-REC-01 | 稳定后可按日期整理原始资料来源和问题；不把未经核实资料标成诊断事实 | 原型待做 |
| ACC-SET-01 | 设置可展示本地目录/数据包状态；取消选择无副作用；资料分享需逐次明确授权 | 原型待做 |
