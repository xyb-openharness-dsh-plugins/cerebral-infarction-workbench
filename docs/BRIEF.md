# 需求起点

来源：初始化配置。用户、场景和流程是有效的SPEC互动素材；继承会话中已有明确确认，其余不能仅因配置通过校验就当成设计定稿或研究验证。

目标用户：脑梗死患者、疑似脑卒中者的陪同家属与照护者；不假设当前用户已确诊或症状稳定。

场景：疑似急性脑卒中时尽快识别危险信号、联系当地急救服务并准备就医信息；出院后整理本人的脑梗死资料用于复诊。

核心流程：
1. 疑似急症时呈现FAST识别与立即联系当地急救服务的入口，记录症状发现时间（如已知）
2. 生成可带去急诊的简要就医准备清单，不延误呼救或院前处置
3. 稳定后由本人或照护者整理脑梗死诊疗资料、来源和随访问题

完成结果：用户可看到急症下一步提示与就医准备清单，并可在稳定后整理可追溯的个人资料；页面不提供疗效承诺或用药指令。

初始布局选择：business-first
