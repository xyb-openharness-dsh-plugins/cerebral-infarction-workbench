# 脑梗死工作台 SPEC v0.1（M1候选）

状态：需求草案；G1自动签认（待晨审追认），不是临床审核、原型签认或生产实现授权。

## 范围与安全目标

面向疑似急性卒中者、脑梗死患者本人及照护者；以中文和中国大陆语境为初稿。第一目标是让疑似卒中者立即联系当地急救服务，不经由表单、AI、登录或定位。院前信息只帮助本人/照护者向急救人员交代；稳定后可整理原始资料及复诊问题。急症页面按“疑似卒中”处理，不能仅凭症状判为脑梗死或排除脑出血/TIA。

不做诊断、个体溶栓/取栓资格评估、治疗/用药/血压建议、等待观察、自驾/具体医院推荐、真实急救调度或治疗结果承诺。指南时窗只作经来源核验的背景信息，不倒数或宣布“已错过”。

## 研究与追踪

公开证据及局限见 `docs/USER-RESEARCH.md`；场景取舍见 `docs/SCENARIOS.md`；功能ID见 `docs/FEATURE-INVENTORY.csv`；HVT审查见 `docs/HVT-REVIEW.md`。关键映射：官方中风120/BEFAST → S1/EMR-01/02 → 症状入口、未知可跳过、当地急救 → ACC-EMR-01/02；患者延迟就医的犹豫和不当自处 → S1/S2/EMR-03 → 先求助、非责备、可口述交接 → ACC-EMR-03。稳定期归档作为次场景，用户需求证据仍弱。

## 功能范围（一期候选）

1. **急症入口**：首屏立即呼叫按钮；中国大陆“120”文案仅在当地部署核实时出现。断网或宿主不支持拨号时，显示手动拨号指引；不要求输入信息。
2. **症状识别**：FAST/中风120 + 突发平衡、视力变化等，任何突发异常均建议立即求助；明确筛查不能排除，症状短暂消失也继续求助。
3. **交接卡**：用户可选填最后正常/首次异常时间、症状、目击者、已知病史/过敏/当前用药。允许未知/跳过。只生成“本人/照护者报告、未经核验”摘要，供口述/复制；不用药建议。
4. **稳定后资料整理**：记录诊疗文书来源、日期、原件位置及问题草稿。AI（若接入）只给候选，用户确认后才保存。
5. **设置与隐私**：患者资料目录、导入模式与参考数据来源状态；默认本地，不因设置保存而授权云传输。目录取消无副作用。

## 交互与失败恢复

交互路径初稿见 `docs/INTERACTION-DESIGN.md`。急症路径所有步骤可跳过，页面无需网络依赖；任何技术错误均不遮挡呼救入口。照护者代填必须标明来源；急症临时资料不默认写入长期患者档案。窄窗/大字/键盘可用性由M2原型验证。
